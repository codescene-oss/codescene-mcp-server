# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in codescene-mcp-server, please report it
using [GitHub Security Advisories](https://github.com/codescene-oss/codescene-mcp-server/security/advisories/new)
rather than opening a public issue.

Please include the affected version, reproduction steps, and potential impact.
We aim to acknowledge reports within 5 business days.
